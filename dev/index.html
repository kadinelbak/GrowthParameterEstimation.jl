GrowthParameterEstimation.jl

GrowthParameterEstimation.jl is a Julia package for fitting growth ordinary differential equation (ODE) models to time-series data. It provides built-in and user-registered growth models, single and joint (shared-parameter) fitting, model comparison by information criteria, staged pipelines that pass parameters from one experiment to the next, uncertainty quantification, and practical and structural identifiability analysis.

Release notes for every version, including breaking changes, are in CHANGELOG.md.

Quick example

using GrowthParameterEstimation

x = collect(0.0:1.0:5.0)
y = [5.0, 8.0, 12.0, 18.0, 22.0, 28.0]
result = run_single_fit(x, y, [0.2, 50.0]; show_stats = false)
result.params, result.bic
