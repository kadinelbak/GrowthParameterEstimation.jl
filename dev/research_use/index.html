Research use

GrowthParameterEstimation.jl was written for, and is used in, mathematical oncology research on drug resistance in ovarian cancer cell lines. Every claim on this page points to a file you can check. Two of the research repositories are private for now (unpublished data), and this page says so where it applies.

What each project uses

A2780 pipeline (CancerGrowthDynamics/Modeling_Approaches/02_mechanical_automatic_package)

A staged pipeline fits a family of autonomous compartment models (no explicit time dependence, so each model can be driven by any dose schedule) and passes the selected model to an optimal-control step for the cisplatin schedule.

Package functionWhere it is usedPurpose
run_joint_fitbootstrap_tools.jl (bs_fit, called by fit_cand for every candidate in every stage)Joint fit of one multi-state model across all trajectories of a stage, with an estimated initial state (u0_builder) where the first count is far from the seeding
generate_multistarts, run_joint_multistartzoo_heldout.jlMultistart refits for held-out validation
evaluate_joint_fitzoo_heldout.jlScoring held-out predictions

The pipeline also follows the schemes of bootstrap_joint_fit, parameter_sensitivity_analysis and blocked_joint_validation, but reimplements them in zoo_analyses.jl: bootstrap_joint_fit cannot yet resample weighted data, parameter_sensitivity_analysis handles one-state models only, and the blocked validation is run locally so that refits use the same residual weights as the main fits (see the comments and method notes in zoo_analyses.jl, lines 8–14, 109, 410, 758 and 871). These are known gaps.

The earlier manual approach (Modeling_Approaches/01_mechanical_manual) also lists the package as a dependency. The neural-network track (03_automatic_neural_network) deliberately does not use it.

OVCAR3 pipeline (parpResearch)

The README of that repository states that "the fitting, multistart, bootstrap, profile-likelihood, Fisher-information and synthetic-recovery machinery is GrowthParameterEstimation.jl", and that the repository holds only the experiment-specific parts (data loading, the population model, stage configuration and reporting).

Outputs that rely on the package

  • The A2780 results site (public): kadinelbak.github.io/CancerGrowthDynamics. Its staged model-comparison, bootstrap, sensitivity and validation reports name the package as the fitting engine.
  • An undergraduate honors thesis (University of Florida, Biomedical Engineering), in preparation, whose methods section describes fitting with GrowthParameterEstimation.jl.
  • A manuscript on the A2780 work, in preparation.
